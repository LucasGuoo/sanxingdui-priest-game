## 一句话介绍
一款以三星堆祭司青铜头像为主题的**节奏命中**网页小游戏：当祭祀光点抵达头像眉心判定圈时按下按键「铸入」仪式之音，连续命中积累「唤醒值」，唤醒沉睡三千年的祭司，并在过程中了解三星堆的馆方文化事实。

## 运行方式（断网可运行 ✅）
本作为**纯前端单文件**，无任何外部依赖、无网络请求，本地电脑断网即可运行。
- 最简单：双击 `index.html` 用浏览器打开即可玩（键盘/鼠标操作）。
- **使用手柄**时，浏览器要求「安全上下文」，**推荐用本地服务器打开**：
  ```bash
  cd 本仓库目录
  python3 -m http.server 8080
  # 浏览器访问 http://localhost:8080
  ```
  （`localhost` 属于安全上下文，Gamepad API 才会生效。）

## 文化事实 vs 艺术演绎（评审必查，已严格分开）
**已核对的馆方文化事实（来自馆方展览海报 / 展签）：**
1. 商代文物（公元前 1600—前1046 年）。— 馆方展签
2. 1986 年出土于四川广汉三星堆二号祭祀坑。— 馆方出土信息
3. 现藏于三星堆博物馆。— 馆方收藏单位
4. 造型特征：头部呈圆筒形，大耳外张，眉眼与鼻部轮廓鲜明。— 馆方展览海报

**本作艺术演绎（非史实，已在游戏与结束页明确标注）：**
- 「祭司以 oversized 的耳朵聆听神谕」——对三星堆大耳的想象。
- 「头像在祭祀中被唤醒」的叙事——为增强互动体验而虚构。

> 游戏规则：文化事实以馆方资料为依据，艺术想象单独标明。游戏内每 4 次命中弹出一条知识点，标签区分为「文化事实 / 艺术演绎」。
